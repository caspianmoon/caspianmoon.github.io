03 / Operating principles

01

Start with the failure.

The interesting problem is rarely the happy path. I look for where users lose trust, state disappears, or agents take the wrong action.

02

Make complexity legible.

Infrastructure becomes valuable when non-specialists can operate it. Good interfaces expose control without exposing chaos.

03

Measure beyond the demo.

A polished first run proves little. Instrument the real workflow, inspect failures, and judge what survives repeated use.
